# Earley parser (C++23)

Реализация алгоритма Эрли (Earley). 
Проект организован так, чтобы `main.cpp` отвечал **только за ввод/вывод**, а вся логика парсера и обработки ввода была вынесена в заголовочные файлы.

## Сборка

Требуется компилятор с поддержкой C++23.

```bash
mkdir build
cd build
cmake ..
./earley_test # или ./prac для обычного запуска
```
