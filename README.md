# Earley parser (C++23)

Реализация алгоритма Эрли (Earley). 

## Сборка

Требуется компилятор с поддержкой C++23.

```bash
mkdir build
cd build
cmake -DEARLEY=ON ..
make
./earley_test # или ./prac для обычного запуска
```

# LR(K) parser (C++23)

Реализация алгоритма LR(K).

## Сборка

Требуется компилятор с поддержкой C++23 (clang-17+ или gcc-14+)

```bash 
mkdir build
cd build 
cmake -DLRK=ON -D K=1 .. # K="число"
make
./lrk_test # или ./prac для обычного запуска
```
